the book it indexes, because that book is an open educational resource and its
licence permits exactly this.

on the site under *Attributions*. They are not decoration: preserving them is a

## This apparatus

Because it reproduces and rearranges that text, this apparatus is an
**adaptation** of a ShareAlike work. It is therefore released under the same

The code is licensed separately and permissively because it is a separate work:
it would run over any text, and nothing in ShareAlike requires the machinery
around a work to adopt the work's licence. Everything that *is* the book, or is
derived from it, stays CC BY-SA 4.0.
